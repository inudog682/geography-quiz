# 高校地理・地図クイズ
`index.html`、`css`、`js` をGitHubリポジトリの同じ階層に配置してください。
地図画像は `assets/world-map-natural-earth.png` という名前で配置します。

このコードは横360度・縦180度の正距円筒図法（equirectangular / Plate Carrée）の地図画像を想定しています。別の投影法では切り出し位置がずれます。地図上の赤い印は概略位置です。河川・山脈・広域地域は今後、線・面として表す改善が必要です。

GitHub Pagesは Settings → Pages → Deploy from a branch → main → /(root) → Save で公開できます。
